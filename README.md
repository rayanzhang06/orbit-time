# 时序 · Orbit

在同一时刻，看见世界。基于三层同心表盘的世界时钟。

## 功能

- 最内圈默认使用设备时区，另外两圈默认约翰内斯堡与墨西哥城。
- 橙色指针固定在顶部，三个城市在顶部的刻度对应同一个时刻；每圈为 24 小时。
- 点击时间环或城市卡片，搜索中文常用城市、英文城市或浏览器支持的 IANA 时区。
- 底部滑块以 15 分钟步长预览前后 12 小时；日期时间输入框使用基准城市的当地时间。
- 自动处理夏令时、跨日和非整小时时差。夏令时跳跃产生的不存在时间会提示；重复时间采用较早的一次。
- 城市与主题保存在当前浏览器；支持移动端、深色模式和键盘操作。
- 复制三个城市的日期与时间，方便安排沟通。

## 本地运行

无需安装依赖。在项目目录启动静态服务器：

```sh
python3 -m http.server 4173
```

访问 http://localhost:4173 。使用 ES Modules，需要 HTTP 服务，不能直接双击 HTML 文件。

## 验证

需要 Node.js 20 或更高版本：

```sh
node --test tests/time.test.js
```

检查范围：城市时差、日期边界、半小时/45分钟时区、南北半球夏令时、当地时间输入的跳跃与重复。

## GitHub Pages

将本目录内容提交到仓库 `main` 分支，在 **Settings → Pages → Source** 选择 **GitHub Actions**。内置工作流在推送时运行测试，并只发布五个静态资源文件。无需密钥、后端或付费 API。

部署配置参考 [GitHub 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 时区说明

时间换算依赖浏览器自带的 `Intl.DateTimeFormat` 与 IANA 时区数据，遵循所选日期的规则。浏览器/操作系统需要保持更新以获取政府调整后的时区规则。日间色带表示 06:00–18:00，不代表真实日出日落；工作时间提示使用当地 09:00–18:00，未排除周末和节假日。

项目使用系统字体，页面资源均在本地，无追踪、外部字体或第三方网络请求。
