# 时序 · Orbit

在同一时刻，看见世界。基于三层同心表盘的世界时钟。

## 功能

- 最内圈默认使用设备时区，另外两圈默认约翰内斯堡与墨西哥城。
- 橙色指针固定在顶部，三个城市在顶部的刻度对应同一个时刻；每圈为 24 小时。
- 每个圆环以暖金色展示日出至日落、雾蓝色展示日落至日出，并用太阳与月亮标记对应区域。按各城市参考坐标及当地日期计算日出日落，随时间预览与城市切换联动，支持极昼、极夜。
- 点击时间环或城市卡片，搜索中文常用城市、英文城市或浏览器支持的 IANA 时区。
- 底部滑块以 15 分钟步长预览前后 12 小时；日期时间输入框使用基准城市的当地时间。
- 自动处理夏令时、跨日和非整小时时差。夏令时跳跃产生的不存在时间会提示；重复时间采用较早的一次。
- 城市与主题保存在当前浏览器；支持移动端、深色模式和键盘操作。
- 复制三个城市的日期与时间，方便安排沟通。

## 本地运行

无需安装依赖。在项目目录启动静态服务器：

```sh
python3 -m http.server 4173
```

访问 http://localhost:4173 。使用 ES Modules，需要 HTTP 服务，不能直接双击 HTML 文件。

## 验证

需要 Node.js 20 或更高版本：

```sh
node --test tests/*.test.js
```

检查范围：城市时差、日期边界、半小时/45分钟时区、夏令时、当地时间输入的跳跃与重复，以及日出日落边界、季节差异、极昼极夜、时区别名与无坐标场景。

## 时区说明

时间换算依赖浏览器自带的 `Intl.DateTimeFormat` 与 IANA 时区数据，遵循所选日期的规则。浏览器/操作系统需要保持更新以获取政府调整后的时区规则。日夜色带依据城市参考坐标和所选当地日期的天文日出日落计算，包含标准大气折射，不计地形、建筑遮挡或实时天气；工作时间提示使用当地 09:00–18:00，未排除周末和节假日。

项目使用系统字体，页面资源均在本地，无追踪、外部字体或第三方网络请求。

## 日照算法与数据

- [SunCalc](https://github.com/mourner/suncalc)：随项目提供 2.1.4 源码快照（2026-11-16），BSD-2-Clause 许可见 `vendor/SUNCALC-LICENSE`。采用太阳上缘升起/落下的标准高度 −0.833°、观测高度 0 米。
- [IANA zone.tab](https://data.iana.org/time-zones/tzdb/zone.tab)：公共领域的时区代表地点坐标。常用城市以对应城市坐标计算；默认使用设备时区对应的代表城市，并非 GPS 定位。
- 北京及新德里坐标来自 [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) 的 [GeoNames](https://www.geonames.org/) 数据（CC BY 4.0），覆盖时区代表坐标，以匹配页面中的城市名称。
- 城市卡片展示所选日期的日出与日落（精确到分钟）；时间环以当地钟表时刻表达。在切换夏令时的日期，同一个钟表时刻可能对应两个实际时刻。
- UTC 等无地理位置的时区不绘制日夜色带，并明确提示无法计算，不采用虚构的日出日落。
